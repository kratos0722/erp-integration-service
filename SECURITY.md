# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.
Instead, report them privately via GitHub Security Advisories
("Report a vulnerability" under the Security tab), including steps to
reproduce and the affected version.

You can expect an acknowledgement within a few days and an update as the
issue is triaged and resolved.

## Scope

This is a reference implementation with no proprietary code or data. Reports
about dependency vulnerabilities and insecure defaults are welcome.
